What Android lets Oistins see. Without root, Android hides other apps' individual connections and the router's hardware address, so this version watches Wi-Fi access points, routers, DNS, encryption, paths, cell towers and per-app data use instead. Cell-tower warnings are signs, not proof. For dedicated IMSI-catcher detection see EFF Rayhunter.
